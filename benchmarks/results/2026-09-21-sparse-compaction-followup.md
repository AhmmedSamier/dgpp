The wide engine test derives its expected graph bucket from the enabled
policy. New sampled lanes use a broad distribution and a one-candidate cap,
assert that each physical mapping reaches fallback, and compare transcripts
across remapping, alternating order and slot reuse. Both policies run at
depth 1; compaction also runs at C16/MTP3 with row-independent kernels.
A local negative-control binary restores physical indexing of compact
fallback logits, so the new lane can demonstrate detection of that error.

`qwen_head_check --compaction off|on` compares fixed teacher tokens at
identical physical slots while changing the captured family. Sparse pairs
in slots 15/0 cover one, two and four rows per request; a five-request case
uses slots 15/0/7/3/12 and a padded six-group compact graph. Dense four- and
sixteen-request cases are exact controls. The analyzer requires complete
rank/case coverage, exact repeats, matching vocabulary ownership, exact
dense controls, and the existing NLL/tie bounds on sparse cases. Drafts are
not generated by this scorer; engine tests separately cover draft and
sampled-fallback state transitions. See `docs/numerics.md` for the protocol.
